# Background Music Instructions

To add your chosen birthday song:
1. Copy your audio file into this folder (`public/music/`).
2. Name the file `song.mp3`.
3. That's it! The website's background music engine will automatically load and play your song.

### Supported formats
- MP3 (recommended: `song.mp3`)
- AAC / M4A / OGG (if you change the audio tag source in `index.html`)

### Current Status
The website is currently pre-configured with play, pause, and mute controls, persistent playback across navigation, and an ambient harmonic chime fallback when no file is present.
