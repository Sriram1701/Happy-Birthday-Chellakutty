# Photo Replacement Guide

This folder contains the 10 Polaroid photo placeholders for the Cherished Memory Gallery.

### How to add your actual photos:
Simply replace the 10 placeholder files with your own photos, keeping the exact names:
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`
- `photo6.jpg`
- `photo7.jpg`
- `photo8.jpg`
- `photo9.jpg`
- `photo10.jpg`

### Recommendations:
- Square (1:1) or portrait (4:5) aspect ratios work best for Polaroid frames.
- Standard resolutions: 800x800px up to 1600x1600px.
- JPG, JPEG, WebP, or PNG (if using PNG/WebP, you can save with a .jpg extension or update the file extensions in `index.html` and `birthday.js`).
